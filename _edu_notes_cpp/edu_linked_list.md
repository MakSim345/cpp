### Размышления на собеседовании

**1. Уточнение задачи:**

> У нас есть односвязный список (каждый узел хранит значение и указатель на следующий). Нужно развернуть его «на месте», то есть так, чтобы первый элемент стал последним, а последний — первым. Дополнительной памяти желательно не использовать.

**2. Мысли вслух:**

* Так как список односвязный, мы не можем идти «назад», только «вперёд».
* Чтобы перевернуть связи, придётся пройти по списку один раз, меняя направление `next`.
* Для этого понадобятся три указателя:

  * `prev` — на предыдущий элемент (изначально `nullptr`),
  * `curr` — на текущий,
  * `next` — чтобы временно хранить следующий элемент перед тем, как мы изменим `curr->next`.

**3. Алгоритм словами:**

* Начинаем с головы списка (`head`).
* Пока текущий элемент не равен `nullptr`:

  * Запоминаем `next = curr->next`.
  * Разворачиваем указатель: `curr->next = prev`.
  * Сдвигаем `prev = curr`, `curr = next`.
* Когда цикл закончится, `prev` указывает на новый «первый» элемент списка. Его и возвращаем как новую голову.

Сложность алгоритма:

* Время — `O(n)`, так как один проход.
* Память — `O(1)`, так как используем только несколько дополнительных указателей.

### Код на C++

```cpp
#include <iostream>

struct Node 
{
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

// Функция для разворота списка
Node* reverseList(Node* head) 
{
    Node* prev = nullptr;
    Node* curr = head;
    Node* next = nullptr;

    while (curr != nullptr) 
    {
        next = curr->next;    // сохраняем следующий элемент
        curr->next = prev;    // переворачиваем ссылку
        prev = curr;          // сдвигаем prev вперёд
        curr = next;          // сдвигаем curr вперёд
    }
    return prev; // новая голова списка
}

// Вспомогательная функция для печати
void printList(Node* head) 
{
    while (head != nullptr) 
    {
        std::cout << head->data << " ";
        head = head->next;
    }
    std::cout << std::endl;
}

int main() 
{
    // Пример: создаём список 1 -> 2 -> 3 -> 4
    Node* head = new Node(1);
    head->next = new Node(2);
    head->next->next = new Node(3);
    head->next->next->next = new Node(4);

    std::cout << "Исходный список: ";
    printList(head);

    head = reverseList(head);

    std::cout << "Перевернутый список: ";
    printList(head);

    return 0;
}
```
